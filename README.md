## Qué hago

Vengo del proceso contable, no de la ingeniería. Durante años ejecuté conciliaciones, cierres y reportería a mano — y eso es justamente lo que me permite automatizarlos bien: sé dónde están los cuellos de botella, qué excepciones importan y qué control no se puede romper.

- **Automatización financiera** — conciliación bancaria y de medios de pago con Python, OCR y Google Apps Script
- **Desarrollo web** — aplicaciones internas con Ruby on Rails y React para procesos financieros y operativos
- **Datos y BI** — SQL, Pandas, Power BI y Tableau para reportería y análisis de variaciones
- **IA aplicada** — agentes y flujos multi-agente para documentar, depurar y acelerar automatizaciones

## Resultados

|  |  |
| :-- | :-- |
