## Sobre mí

Vengo del proceso contable, no de la ingeniería.

Durante más de 15 años ejecuté conciliaciones, cierres y reportería a mano. Aprendí a programar para dejar de hacerlo — y eso es justamente lo que me permite automatizar bien: sé dónde están los cuellos de botella, qué excepciones importan y qué control no se puede romper.

Hoy concilio hasta **20.000 transacciones mensuales** entre bancos y pasarelas de pago con flujos que construyo en Python, y desarrollo aplicaciones internas en Ruby on Rails y React para soportar procesos financieros.

## Qué hago

| | |
| :-- | :-- |
| **Automatización financiera** | Conciliación bancaria y de medios de pago con Python, OCR y Google Apps Script |
| **Desarrollo web** | Aplicaciones internas con Ruby on Rails, React y JavaScript |
| **Datos y BI** | SQL, Pandas, Power BI y Tableau para reportería y análisis de variaciones |
| **IA aplicada** | Agentes y flujos multi-agente para documentar, depurar y acelerar automatizaciones |
